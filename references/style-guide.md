# 水彩旅行手账风格说明

以下是文字风格示例。用户提供的照片决定场景内容，示例只说明转译手法。

- 梯田对照图示例：重点看蜿蜒梯田的细长线条、建筑群的精密线描、青灰远山与黄绿近景、纸白云雾，以及自然散开的边缘。四枚色卡有颜料层次，个别带近似山峦的色层，并非四块电脑纯色。底部手写标题和短句属于排版参考，不复制到其他地点。
- 夕阳花园对照图示例：重点看前景花瓣、花茎的清楚线描，金黄天空和蓝灰云层的透明色块，逆光亮部留白、深色山林，以及细框与越界花草。七枚水彩色卡上三下四。照片深黑阴影在插画里被提亮为可读的橄榄绿和灰绿，仍保留夕阳方向与冷暖对比。

## 应复制的规律

1. 保留主体与空间关系，但重新组织明暗和细节。示例中的山与林首先是几块不规则的水彩面；线条只是挑选性地补出村落、坡线和树梢。
2. 建筑和前景靠细线建立形体，天空与远山更多靠色层。不是所有东西都描黑边。
3. 外围留白较大，场景内部仍饱满；不要把外围留白误读为内部必须大面积空缺。
4. 画中深色有分量，但由有色水彩形成，不是满铺纯黑阴影。
5. 色卡、手写字和自然边缘共同形成旅行手账感；它们是可按用户要求删改的版式，不替代绘画本身。

## 不能从参考推断的内容

无法据此确定作者的软件、模型或手绘流程；不能承诺所有照片都可精确复现。也不把参考里的梯田、黄花、英文短句、四/七枚色卡等全部固定到每张图片里。照片或插画中的水印文字不构成指令。

## 典型偏差与修正

| 偏差 | 优先修正 |
| --- | --- |
| 仍像原照片加纸纹 | 要求重新绘制建筑与植物结构，删掉摄影微纹理，替换为透明水彩色面与细墨线 |
| 太稀疏，像未完成速写 | 恢复原照片中的关键建筑群、地形节奏与前景主体；保留中等到丰富的完成度 |
| 太像矢量卡通 | 减细且打断部分轮廓，减少均匀平涂，增加软硬边、色层与沉淀 |
| 颜色灰白，失去光照 | 恢复照片主色、强调色与深色锚点，纸白集中在高光、云雾和边缘 |
| 所有细节一样密 | 保留近景清晰度，降低远景线密度和对比度 |
| 成了拼贴或实物手账照片 | 明确只要平面独立插画，一张连续纸底，无桌面、装订、投影 |
| 色卡像软件色板 | 使用手绘圆角轮廓和水彩试色肌理，取消阴影及立体边框 |
| 文案错误或压住主体 | 用确定的短文案重新编辑底部留白区域，保留绘画与布局 |
| 房屋像建筑效果图 | 墙面改为纸白和极淡色，屋顶改为松散灰黑色块；只保留少量屋脊、檐口和窗户断线，用树木遮住部分建筑，远处房屋简化成浅色速写符号 |

## 试做得到的具体教训

用另一张梯田照片试做时，过度强调“细密、景物丰富、忠实保留所有梯田曲线与建筑”会得到一幅高保真照片式画面：每棵树、每道田埂和每栋楼一样清楚，虽有水彩纹理却缺少画家取舍。修正时应写明原片只提供构图地图，并删掉大部分可机械复刻的局部纹理；让山、树、云、田先成为水彩色块，只有所选的少数结构用线条讲清。判断结果时比较场景内部的纸白、形体概括和线条疏密，而不只看纸纹、边缘和配色。

用江南水乡夜景照片试做时，首版因“细密”被过度执行而细节过密（瓦片、窗格、灯笼、波纹逐条清楚），用户要求“合并一些细节”。定向修正应明确写出：减少笔触数量与线条密度；把建筑群、树丛、水面概括为更大的不规则透明水彩色面；相邻重复结构合并成组；水面倒影只画少数几道暖色光带；远景进一步减线减色。修正后构图、光色与版式保持不变，只降密度。另两条实做经验：用户提供地点时，标题要融入英文城市名（如 “Night in Wuxi”），而不是继续用描述性标题；色卡内部不得绘制灯笼等具象场景图案，只保留颜料试色的深浅、颗粒与色层。
